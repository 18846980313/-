方法说明

对象（Object）是无序的"属性名 : 属性值"集合，用花括号 { } 表示。 它像一张档案卡：属性名是栏目名，属性值是填进去的内容；值也可以是函数（这时叫方法）或另一个对象（嵌套）。

小结：对象与数组就像档案卡与一排格子 —— 数组按下标 0、1、2 找东西，对象按属性名找东西。 访问用 obj.key 或 obj["key"]；增删改直接赋值或 delete；遍历用 for...in 或 Object.keys/values/entries。 特别注意：对象是引用类型，赋值只是复制"卡片的地址"；要复制卡片本身得用 Object.assign() 或 { ...obj }。
