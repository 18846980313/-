李佳的JavaScript —— 程序结构（循环与条件）

程序三大结构：顺序、分支（条件）、循环。本页重点演示条件结构与循环结构。

一、条件结构（if...else if...else）

function lj_getGrade(lj_score){
    if(lj_score >= 90){
        return "优秀";
    }else if(lj_score >= 80){
        return "良好";
    }else if(lj_score >= 60){
        return "及格";
    }else{
        return "不及格";
    }
}
输入分数后点击按钮，用条件结构判断成绩等级。

    for(var lj_j = 1; lj_j <= lj_i; lj_j++){ // 内层控制列
        // 输出 lj_j × lj_i = 乘积
    }
}

三、循环结构（while 与 do-while）

// while：先判断后执行 —— 1 累加到 100
var lj_total = 0;
var lj_k = 1;
while(lj_k <= 100){
    lj_total += lj_k;
    lj_k++;
}

// do-while：先执行后判断，至少执行一次 —— 5 到 1 倒计时
var lj_count = 5;
do{
    lj_count--;   // 输出倒计时
}while(lj_count > 0);
小结：while 是"先判断后执行"，条件不满足时一次都不执行；do-while 是"先执行后判断"，至少执行一次。循环与条件可以嵌套使用，例如 15-1 的"逢7过"就是 for 循环内嵌套条件判断的组合。
