JSON 展示

JSON（JavaScript Object Notation）—— 轻量级的数据交换格式，易于人阅读，也易于机器解析

一、JSON 的六种值类型

字符串 String

必须用双引号包裹

"name": "李佳"

数字 Number

整数或小数，不加引号

"score": 95.5

布尔 Boolean

只有 true / false 两个值

"isMember": true

空值 null

表示"没有值"（注意不是 undefined）

"remark": null

对象 Object

花括号包裹的键值对集合

"score": { "web": 95 }

数组 Array

方括号包裹的有序列表

"courses": ["网页", "JS"]

二、JSON 与 JS 对象的对比

JS 对象（写法灵活）

var lj_stu = {
    name: "李佳",          // 键可以不加引号
    age: 20,
    hello: function(){    // 可以有函数
        return "hi";
    },
    score: undefined      // 可以有 undefined
};

JSON（格式严格）

{
    "name": "李佳",        // 键必须双引号
    "age": 20,             // 值不能是函数
    "score": null          // 不能出现 undefined
}

五、JSON 的四个常见错误

  • 键使用了单引号：{ 'name': '李佳' } —— 必须用双引号
  • 最后一个键值对后面有逗号：{ "a": 1, } —— JSON 不允许尾逗号
  • JSON 里写注释：{ // 注释 } —— JSON 不支持注释
  • 值里出现 undefined / function —— 只能是六种值类型之一
