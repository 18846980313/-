Web 前端长度单位

CSS 中的绝对单位与相对单位

绝对长度单位

px（像素）
最常用的绝对单位，1px 对应屏幕上的一个物理像素点（CSS 像素）。
width: 300px;
pt（点）
印刷单位，1pt = 1/72 英寸。多用于打印样式。
font-size: 12pt;
in（英寸）
1in = 2.54cm = 96px。
width: 2in;
cm（厘米）
1cm = 37.8px。适合打印排版。
margin: 1cm;
mm（毫米）
1mm = 3.78px。
padding: 5mm;
pc（派卡）
1pc = 12pt。
font-size: 1pc;

相对长度单位

em
相对于父元素 font-size 的倍数。
font-size: 2em;
rem
相对于根元素（html）font-size 的倍数，避免嵌套影响。
font-size: 1.5rem;
vw
相对于视口宽度的百分比，1vw = 1% 视口宽度。
width: 50vw;
vh
相对于视口高度的百分比，1vh = 1% 视口高度。
height: 100vh;
vmin
取 vw 和 vmin 中较小的那个值的百分比。
font-size: 4vmin;
vmax
取 vw 和 vmax 中较大的那个值的百分比。
font-size: 4vmax;
%
相对于父元素对应属性的百分比。
width: 80%;
ch
相对于当前字体中 "0" 字符宽度的倍数。
width: 40ch;

单位对比演示

width: 300px
font-size: 24px → 2em = 48px
font-size: 16px → 2rem = 32px
width: 50vw
height: 80px
width: 60%

选择建议

场景 推荐单位 原因
字体大小 rem 不受嵌套影响，便于全局调整
布局宽度 % vw 响应式适配
边框、间距 px 精确控制，不随字体变化
全屏遮罩 vw vh 始终铺满视口
内部元素间距 em 随父元素字体大小缩放
