Font Awesome 字体图标

使用 webfont 字体文件渲染矢量图标，通过 CSS 类名调用

原理说明

Font Awesome 将图标做成字体（woff2），用 @font-face 加载字体文件，再通过 CSS 伪元素 ::before 输出对应的 Unicode 字符，从而显示为图标。

1. 下载 fontawesome.min.css 与 fa-solid-900.woff2 到本地 cdn 目录；
2. 页面通过 <link rel="stylesheet" href="./cdn/fontawesome.min.css"> 引入样式；
3. 使用 <i class="fa-solid fa-xxx"></i> 即可显示图标。

尺寸控制

通过内置类 fa-xs / fa-sm / fa-lg / fa-2x … fa-10x 或自定义 font-size 调整图标大小。

16px 28px 42px fa-2x fa-4x fa-6x

按钮与颜色应用

图标可直接与按钮组合，配合颜色与渐变背景，灵活适配界面风格。
