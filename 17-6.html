异步包饺子 🥟

用 Promise 和 async/await 编排做饺子的每一步，setTimeout 模拟每道工序的耗时

一、包饺子流程（模拟耗时）

步骤耗时说明
🛒 买原料6 秒异步任务一，买面粉、肉、菜
🥬 取原料2 秒等原料买完才能取，必须等上一步
🥣 和面 + 🥟 和馅4 秒 / 5 秒同时进行，用 Promise.all 等两个都完成（按慢的 5 秒算）
🥟 包饺子3 秒面和馅都好了才能包
🍽 吃饺子1 秒包完就吃！

串行部分 6+2=8 秒，并行部分只等最慢的 5 秒，再加 3+1 秒，全程约 17 秒。等待期间页面完全流畅，这就是异步的好处。

三、两种写法代码对比

写法一：Promise 链式调用

// 每个步骤都返回一个 Promise
function lj_buy(){ return lj_step("买原料", 6000); }

lj_buy()
  .then(lj_take)                      // 买完 → 取原料
  .then(function(){
    // 和面、和馅同时开始
    return Promise.all([lj_dough(), lj_filling()]);
  })
  .then(lj_wrap)                    // 都好了 → 包饺子
  .then(lj_eat)                     // 包完 → 吃饺子
  .then(function(){ console.log("全部完成！"); });

写法二：async/await（推荐）

async function lj_cook(){
  await lj_buy();        // 等买原料完成
  await lj_take();       // 等取原料完成
  // 和面、和馅同时开始，等两个都完成
  await Promise.all([lj_dough(), lj_filling()]);
  await lj_wrap();       // 等包饺子完成
  await lj_eat();        // 等吃饺子完成
  console.log("全部完成！");
}
// await 只能写在 async 函数里，代码像同步一样好读
